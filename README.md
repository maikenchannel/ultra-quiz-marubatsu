# アメリカ横断ウルトラクイズ風 ○×勝ち残りクイズ

「アメリカ横断ウルトラクイズ」を模した、○×勝ち残りクイズのWebサイトです（ファンメイド・非公式）。

- 大会モード：CPU 49人＋あなた＝50人で勝ち残り。間違えたら即脱落、最後の1人になれば優勝
- 1人モード：何問勝ち残れるかに挑戦
- 制限時間10秒（ON/OFF可）、○エリア／×エリアの移動演出、脱落演出つき

## 問題の書き換え方（questions.csv）

問題と正解はすべて `questions.csv` で管理します。

```csv
question,answer
アメリカの首都はニューヨークである,2
自由の女神はフランスから贈られた,1
```

- 1行目はヘッダー `question,answer`
- `answer` は **○なら `1`、×なら `2`**
- 問題文にカンマを含む場合はダブルクォートで囲む： `"東京は,日本の首都である",1`

書き換え方法は2通りあります。

1. **このリポジトリの `questions.csv` を直接編集して push する** → GitHub Pagesに自動で反映されます
2. **サイト内の「問題を編集」画面**で編集・CSV読み込みを行い、「questions.csv をダウンロード」して差し替える

また、チャットで「○○という問題を追加して」「△△の正解を×に変えて」のように指示すれば、こちらでCSVを書き換えます。

## GitHub Pagesでの公開方法

1. このフォルダの中身（`index.html` / `style.css` / `app.js` / `questions.csv` / `README.md`）をGitHubリポジトリのルートに置く
2. リポジトリの **Settings → Pages** を開く
3. **Build and deployment → Source: Deploy from a branch**、Branch: `main` / `(root)` を選んで Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
