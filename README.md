# アメリカ横断ウルトラクイズ風 ○×勝ち残りクイズ

「アメリカ横断ウルトラクイズ」を模した、○×勝ち残りクイズのWebサイトです（ファンメイド・非公式）。

公開サイト: https://maikenchannel.github.io/ultra-quiz-marubatsu/

## 遊び方

- 大会モード：CPUと合わせて50人で勝ち残り。間違えたら即脱落、最後の1人になれば優勝
- 1人モード：何問勝ち残れるかに挑戦
- オンライン対戦：自動マッチング（待機枠方式）と部屋コード参加の2通り。ブラウザ同士の直接通信（WebRTC）で行い、人数が足りない分はCPUが補います。チャット機能はありません
- 流れは自動進行：出題→シンキングタイム30秒→解答提示→次の問題へ自動遷移
- フィールドは野球場風の3D表示で、回答すると選手が○（レフト側）／×（ライト側）へ移動し、不正解の選手は倒れて脱落します。解答提示は野球場中央上部のオーロラビジョン（大型ビジョン）で行います

## 技術メモ

- 静的なサイトです（GitHub Pagesで配信）
- 3D表示：Three.js（ローポリゴン）
- オンライン対戦の接続取り次ぎ：PeerJS Cloud（対戦データはブラウザ間で直接送受信し、このサイトのサーバーが中継・保存することはありません）
